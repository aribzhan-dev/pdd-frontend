# pdd_frontend

Интерфейс платформы ПДД: вход, каталог тем, прохождение теста, разбор
результата и админка для персонала.

API живёт в отдельном репозитории — `pdd_backend`.

## Стек

React 18 · TypeScript (strict) · react-router 6 · Vite 5 · обычный CSS с
токенами

Tailwind и библиотеки компонентов не подключены: дизайн подогнан под
конкретный макет, а все цвета, отступы и радиусы объявлены один раз в
`styles/tokens.css`.

## Структура

Feature-sliced: каждый экран в своей папке вместе со своим CSS.

```
src/
├── main.tsx              монтирование и импорт стилей
├── app/                  App.tsx (язык, провайдеры), routes.tsx
├── api/                  единственная дверь наружу
│   ├── client.ts         токен, повтор запроса после refresh
│   └── auth · content · quiz · staff
├── features/
│   ├── auth/             контекст пользователя, страница входа
│   ├── catalog/          темы, выбор режима теста
│   ├── quiz/             прохождение, таймер, навигация, результат
│   ├── history/          прошлые попытки
│   └── staff/            студенты и менеджеры
├── components/           Header, LanguageSwitch, поля, ConfirmDialog
├── lib/                  storage (токен), format (дата, время)
├── i18n/strings.ts       тексты интерфейса
├── types/api.ts          типы ответов API
└── styles/               tokens.css + global.css
```

## Как устроено прохождение теста

Состояние живёт на сервере, а не в браузере. `useQuizSession` при загрузке
спрашивает `GET /quiz/active` и получает порядок вопросов, все данные ответы,
текущую позицию и остаток времени. В браузере хранится только токен.

Отсюда следует, что перезагрузка страницы ничего не теряет, а таймер
экзамена не начинается заново.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
```

Нужен запущенный backend на `http://localhost:8000` — `vite.config.ts`
проксирует на него `/api` и `/media`, поэтому браузер остаётся на одном
источнике и обходится без CORS.

```bash
npm run typecheck
npm run build      # результат в dist/
```

## Деплой

`npm run build` и раздача `dist/` через nginx с `try_files $uri /index.html`:
маршрутизация происходит в браузере, поэтому любой путь должен отдавать
`index.html`. Полностью — в `DEPLOY.md` репозитория `pdd_backend`.
